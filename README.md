# MavRent Platform

Commercial rebuild of MavRent for landlords, property managers, real-estate agents and tenants.

## Product
Property management, rent operations, maintenance, vacancy advertising, rental marketplace, applications, communications, Mav AI, subscriptions and business analytics.

## Stack
Next.js App Router, TypeScript, Supabase and Vercel.

## Security
Service-role credentials remain server-side. Database authorization is designed around organization membership and row-level security.

## Environment
See .env.example. Never commit production secrets.
